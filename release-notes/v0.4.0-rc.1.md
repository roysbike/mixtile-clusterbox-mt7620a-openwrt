# ClusterBox BMC firmware v0.4.0-rc.1

**In one sentence:** the BMC firmware on a current OpenWrt: 25.12.5 with
Linux 6.12 instead of 23.05 with Linux 5.15, without the parts the
Cluster Box does not use.

Release candidate. OpenMIOP is unchanged (Stack v0.5.0: `omi-rc` with
gateway pull and zero-copy); blades need no update.

> [!WARNING]
> First firmware on a new kernel. Updating reboots the BMC (every blade
> link resets for the length of its boot). Keep a microSD card for
> recovery at hand. With DRBD 9.3.4 on the blades check first that no
> replica holds `out-of-sync` bits
> ([LINBIT/drbd#153](https://github.com/LINBIT/drbd/issues/153)), and the
> databases afterwards.

## What changes

- **OpenWrt 25.12.5, Linux 6.12.94.** Package manager is apk (`apk add`,
  `apk list --installed`) instead of opkg.
- **Left out:** Wi-Fi (no radio in the box), PPP/PPPoE, OpenVPN, DDNS,
  rarely used tools, Mixtile's vendor `miop.ko`. Settings for them in
  `/etc/config` stay but do nothing.
- **Fans** on the upstream `pwm-gpio` driver; fan speed setting works as
  before (nodectl, LuCI). Fan RPM is no longer reported (it was always 0).
- **LuCI** shows `OpenWrt 25.12.5 ClusterBox v0.4.0-rc.1`. Not carried
  over yet: password change for a non-root user in LuCI and the
  "Online Update" button on the flash page (use *Firmware Update*).
- ch343 console driver V2.2; files in `/rom` owned by root.

Full list: [CHANGELOG.md](https://github.com/roysbike/mixtile-clusterbox-mt7620a-openwrt/blob/v0.4.0-rc.1/CHANGELOG.md).

## Update

```sh
uci set mixtile-update.main.channel=rc; uci commit mixtile-update
mixtile-update check && mixtile-update download && mixtile-update verify && mixtile-update install --yes
```

After the reboot:

```sh
cat /etc/mixtile-release                      # FIRMWARE_VERSION="v0.4.0-rc.1"
uname -r                                      # 6.12.94
dmesg | grep omi0                             # "node N active: ..., gateway pull[, zero-copy]"
ls /dev/ttyCH343USB*                          # four blade consoles
cat /sys/class/pwm/pwmchip0/pwm0/duty_cycle   # fan running
nodectl status --all
```

## Tested

Built and inspected in CI (`scripts/clusterbox/verify-firmware.sh`):
metadata for `cluster-box-control-V120`, kernel 6.12.94, all 56 modules
for MIPS and this kernel, `omi-rc` with gateway pull and zero-copy,
ch343, fan-boot, nodectl, mixtile-update, flow offloading, no Wi-Fi /
PPP / OpenVPN / `miop.ko`. **Not yet flashed on hardware.**
